Artilheiro Defender

Setas ← e → ou A e D para mover. Espaço para ATIRAR. P para PAUSAR

Pontos: 0 Vidas: 3 Ondas: 1

Mini Game Espacial do Arthur Dimer de Oliveira

Quando um inimigo escapa pela parte inferior da tela, o jogador perde 1 vida. O jogador deve sentir urgência porque cada inimigo ignorado aproxima a derrota. A movimentação constante e a precisão dos tiros são essenciais para sobreviver. As ondas ficam progressivamente mais difíceis. A partida termina quando as vidas chegam a zero.

Créditos

Arthur Dimer de Oliveira e Jefferson Tijik
