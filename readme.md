Cyber Snake
Como jogar: Use WASD ou as setas do teclado para controlar a cobra e coletar alimentos.

Diferencial: O mapa possui um bloco vermelho que elimina a cobra em caso de colisão, exigindo mais estratégia que o Snake clássico.

Créditos: Desenvolvido por Arthur Dimer de Oliveira para a atividade de Level Design e Gameplay.
